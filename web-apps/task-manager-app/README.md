# Task Manager App

A modern, feature-rich task management web application built with vanilla HTML, CSS, and JavaScript.

## Features

✅ **Task Management**
- Add new tasks with a simple, intuitive interface
- Edit existing tasks inline
- Delete tasks with confirmation
- Mark tasks as complete/incomplete

✅ **Priority Levels**
- Low (Gray)
- Medium (Yellow)
- High (Red)
- Visual color-coding for easy identification

✅ **Filtering & Search**
- View all tasks
- Filter by active tasks
- Filter by completed tasks
- Real-time search functionality

✅ **Data Persistence**
- All tasks saved to localStorage
- Data persists across browser sessions

✅ **Theme Support**
- Light mode (default)
- Dark mode
- Theme preference saved

✅ **Responsive Design**
- Mobile-friendly interface
- Adapts to all screen sizes
- Touch-optimized controls

## Usage

1. Open `index.html` in any modern web browser
2. Add tasks using the input field
3. Select priority level before adding
4. Use search and filters to organize your view
5. Click edit to modify tasks
6. Check the checkbox to mark tasks complete
7. Toggle dark mode with the moon/sun button
